# 剪辑经验规范（editing heuristics）

本文件是 autoedit-agent 在文案（阶段 3）、蓝图（阶段 4）与审计（阶段 6）时
引用的默认经验值。用户给出自己的节奏与风格偏好时，以用户偏好为准；
用户没给时，按本文执行，并在产出中注明「按默认规范」。

## 1. 节奏密度

按内容类型控制平均镜头时长（ASL），别全程一个速度：

| 内容类型 | 建议 ASL | 说明 |
|---|---|---|
| 快节奏短视频（≤60s） | 1.5–3s | 前 3 秒必须出现钩子画面或钩子字幕 |
| 叙事/纪录短片 | 3–6s | 情绪段落可放宽到 8s，但连续两个长镜头之间要换景别 |
| 口播/访谈 | 4–8s | 靠跳切与 B-roll 换气，不要靠加速 |
| 产品演示 | 3–5s | 一个动作一个镜头，动作没做完不切 |

通用规则：
- 同一机位同一景别的连续画面超过 10 秒，观众注意力明显下滑：要么切 B-roll，要么放大到特写（画幅允许时）。
- 高潮段密度可以比平均值密 30% 左右；铺垫段则反过来，密度降下来才有对比。
- 成片前 15 秒不要出现超过 2 秒的纯空镜，除非空镜本身就是钩子。

## 2. J-cut 与 L-cut

- **J-cut（声音先行）**：下一镜头的声音提前 0.3–1.0 秒进入，画面随后跟上。
  适合场景转换、访谈切入、悬念引出。在蓝图里表现为：音频起点比视频起点早，
  若工具链只能整段对齐，至少在备注里标出意图，供人工微调。
- **L-cut（声音延续）**：上一镜头的声音延续到下一镜头开始后 0.3–1.5 秒。
  适合反应镜头（说话者说完，切听者反应，声音还在）、情绪留白。
- 原则：J/L-cut 是用来「缝合」转场的，不是每切必用；一段 3 分钟的片子用 3–6 处足够，
  用多了反而显得黏。硬切（cut）永远是默认选项，拿不准就硬切。

## 3. 跳切处理

口播与访谈删气口、删口误必然产生跳切，处理顺序按优先级：
1. **能盖就盖**：跳切点上压 B-roll、图示或字幕强调，观众根本注意不到切点。
2. **能推就推**：跳切两侧景别做出差异（如中景 → 近景推近 15%–30%），把跳切伪装成有意的景别变化。
3. **能顺就顺**：相邻句之间保留 0.2–0.4 秒的自然气口，不要贴脸剪到零间隙，呼吸没了人就像机器人。
4. 实在盖不住的跳切，保持人物在画面中的位置与大小一致（跳幅越小越不违和），
   并且不要在一句话中间跳超过一次。

删除静音段时注意：analysis 标记的静音不等于都该删。
语气停顿、情绪留白是有信息的，删气口只删「无信息的长静音」（经验值：口播中 > 1.2 秒的纯静音可压缩到 0.3 秒左右）。

## 4. 字幕断句

- 单行字幕长度：中文 ≤ 16 字、英文 ≤ 42 字符；竖屏再减 2–4 字。超长就断句，不要缩小字号硬塞。
- 断句断在语义边界：标点 > 词组边界 > 主谓之间；禁止把人名、数字与单位、固定搭配拆到两行。
- 一条字幕的停留时长：最短 0.8 秒，最长 7 秒；按阅读速度估算，中文约每秒 4–5 字是舒适上限。
- 字幕与旁白必须逐字一致（断句可以不同）；字幕里不要出现旁白没有的补充信息，会让观众分心。
- 关键词强调（变色/放大）一条片子不超过 5 处，处处强调等于没有强调。

## 5. 安全区

- **标题安全区**：重要文字、人物面部不要贴边，距画面边缘至少保留 5% 的边距（沿用经典 title safe 的思路）。
- **平台 UI 遮挡**（竖屏短视频尤其注意）：底部约 15% 是标题/文案区，右侧约 12% 是点赞评论按钮列，
  顶部约 8% 是状态与搜索栏——关键信息、字幕主行避开这三带；字幕放在底部遮挡带之上。
- **字幕安全边距**：16:9 时字幕底边距画面底部约 6%–8%；9:16 时约 18%（给平台文案区让位）。
- 人物眼睛位置尽量落在画面上三分之一附近，别让头顶留白超过画面高度的 25%（除非有意的大留白构图）。

## 6. 声音

- 人声是基准：成片综合响度以「手机外放能听清每个字」为准，BGM 永远给人声让路。
- 有人声的段落，BGM 建议 -20dB 上下（相对人声峰值），无人声的空镜/转场段可以回到 -12dB 左右。
- BGM 起止用 0.5–1.5 秒淡入淡出，不要硬起硬停；换曲点对齐在镜头切换点或文案段落点上。
- 环境声不要全程垫满：关键动作声（开门、倒水、机器启动）保留原声，是真实感的主要来源。

## 7. 结构自检（阶段 3 / 4 交稿前过一遍）

- [ ] 每段文案都有真实素材承接，没有「无米之炊」的段落；
- [ ] 没有连续两个以上同景别同机位的长镜头；
- [ ] 跳切都已按第 3 节至少处理到第 3 级；
- [ ] 字幕全部符合第 4 节断句与时长；
- [ ] 关键信息没有落进第 5 节的遮挡带；
- [ ] 收尾段有明确结论或行动点，不是播着播着就没了。
